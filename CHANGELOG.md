# Changelog

## 4.3.1 — 2026-08-21

- Improved the GrowCube connection interface.
- Updated the device setup flow for clearer Wi‑Fi and Bluetooth steps.
- Changed Networking mode: Wi‑Fi network name and password are now sent to GrowCube via Bluetooth during setup.
- Changed Direct mode: GrowCube is controlled exclusively over Bluetooth Low Energy (BLE), without requiring Wi‑Fi.
