# Changelog

## 4.3.2 — 2026-08-22

- Improved the first-time GrowCube setup interface.
- Fixed an issue that prevented a factory-reset GrowCube from being added again when its previous entry was still saved in the app. The app now detects the existing GrowCube and lets the user either restore it with its previous data or set it up as a new device.
- Fixed the GrowCube reset sequence so that confirmation sounds now play correctly.

## 4.3.1 — 2026-08-21

- Improved the GrowCube connection interface.
- Updated the device setup flow for clearer Wi‑Fi and Bluetooth steps.
- Changed Networking mode: Wi‑Fi network name and password are now sent to GrowCube via Bluetooth during setup.
- Changed Direct mode: GrowCube is controlled exclusively over Bluetooth Low Energy (BLE), without requiring Wi‑Fi.
