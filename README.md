# GrowCube firmware — version 4.2

ESP8266 firmware for GrowCube and a Windows flashing utility are available in [`GrowCube_firmware_V_4_2`](GrowCube_firmware_V_4_2/).

Keep the `.bin` firmware file next to `flash_tool.exe`, then run the flashing utility on Windows.

# GrowCube Android application — version 4.2

The ready-to-install Android APK is available in [`Android_app`](Android_app/).
